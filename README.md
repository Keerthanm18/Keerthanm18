# RTL Design & Functional Verification

This repository includes RTL design and verification projects implemented using Verilog/SystemVerilog, focusing on simulation-driven validation and debugging.

## 🔧 Tools
- Verilog / SystemVerilog  
- Cadence Xcelium,Synopsys VCS,Siemens Questa,ModelSim  

## 📌 Projects

### 🔹 Synchronous FIFO
- Designed parameterized FIFO using read/write pointer architecture  
- Implemented full/empty flag logic using pointer comparison  
- Verified using directed testbench with overflow/underflow scenarios  
- Performed waveform-based debugging for data integrity  

### 🔹 Hamming (7,4) Code
- Implemented encoder/decoder for single-bit error correction  
- Used parity generation and syndrome calculation logic  
- Verified using testbench with error injection cases  

## 🧠 Verification Focus
- Functional verification  
- Testbench development (stimulus + checking)  
- Corner case validation  
- Waveform analysis & debugging
